# Обложки Ripster: размеры и зум

## Правило по всему приложению
- **Сетки/карточки грузят МЕЛКИЙ thumbnail** (≈300px) — трафик и скорость декода
  (карточка ~180px, декодировать 1000² вместо 300² = рывки прокрутки).
- **Зум (клик по обложке) открывает ≈1000×1000** — крупная версия под лайтбокс.

`relCover(url, px)` (в `sc_tab.js`) апгрейдит адрес обложки под нужный размер,
по-разному для каждого CDN. Поддержаны (проверено 02.08.2026):
- Spotify `i.scdn.co/image/ab67616d0000…`: 4851(64) / 1e02(300) / b273(640 — потолок).
- Apple `mzstatic.com`: сегмент `/{N}x{N}bb.jpg`, N до 1000.
- Deezer `dzcdn.net`: `/{N}x{N}-…`, N до 1000.
- Tidal `resources.tidal.com`: `/{N}x{N}.jpg`, живы 80/160/320/640/**1280**.
- Qobuz `qobuz.com`: суффикс `_{N}.jpg` → `_org` (оригинал) для зума.
Незнакомый CDN — отдаём как есть.

Лайтбокс (`lightbox.js`) при клике сам зовёт `relCover(base, 1000)` — поэтому
НЕ нужно прописывать крупный `data-lightbox-src` в каждой карточке; хватает
`data-lightbox` на `<img>`, а зум апгрейдит текущий `src`.

## 🔴 «Увеличиваю, а там пусто, только темнеет»
Лайтбокс открывался (фон темнел), но картинки не было. Две причины, обе про то,
что крупная версия **не ошибается, а ВИСИТ**:

1. Крупный URL (Tidal 1280 / Apple 1000) для части обложек грузится **медленно**
   или недоступен. `img.onerror` на висяк/таймаут **не срабатывает** — значит откат
   «по onerror на thumbnail» НЕ помогает: элемент просто вечно «грузится» на пустом.

**Фикс (thumbnail-first).** `openLightbox(hi, thumb)` ставит `img.src = thumb`
СРАЗУ (пусто не будет никогда), а `hi` (1000) грузит в фоне через `new Image()` и
подменяет `img.src` только по `onload`. Зависла/битая крупная — остаётся thumbnail.
Не полагаться на `onerror` для отката: висяк его не вызывает.

## Проверка (headless)
- Клик по обложке → `#lightbox-img` `src` НЕ пустой сразу (thumbnail виден мгновенно).
- `relCover(url,1000)` для каждого CDN даёт корректный крупный URL — проверить
  `curl -o /dev/null -w "%{http_code}"` (Tidal 1280x1280 → 200 и т.п.).
- Помни: в headless крупные картинки часто «таймаутят» из-за сети профиля — это НЕ
  признак битого URL; проверяй URL отдельным curl с хорошей сетью.

Кэш WebView2: после правки подними `lightbox.js?v=`/`sc_tab.js?v=` и hard-reload окна.
